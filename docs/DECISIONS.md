초기 실행: `python -m soc.kb.inspect --strategy fast` (Unstructured 0.27.37, 2026-11-17). 위 숫자는 **표 복원 전, 필터 전** 요소 수로 남겨 둔 비교 기준이다. 지금의 `parse_pdf(..., "fast")`는 01·09번에 표 좌표 복원을 추가하므로 이 숫자와 다르게 출력된다.

`drop_header_footer()`는 여러 페이지에 **같은 문구로 반복된** `Header`/`Footer`만 제거한다. 03번에서 반복 문구 4개를 제거했으며, 절 제목 2개는 보존했다. 유일한 `Header`에는 본문이나 표 제목이 섞여 있어 일괄 삭제하지 않았다.

### 01·09번 표 관계 복원 (D1-7 후 보정)

- `hi_res`도 비교했다. 01번은 `Table` 2개, 09번은 5개를 찾았으나 한국어 셀 내용과 헤더가 잘못 인식돼 승인권자 판단에 그대로 쓰기 어려웠다. 따라서 `fast`가 읽은 원본 글자와 PDF 표의 칸 좌표를 결합했다.
- `parse.py`는 01·09번의 `fast` 결과에서 표 안의 흩어진 텍스트를 제외하고, 각 행을 `Table` 요소로 다시 만든다. 09번은 자산 등급·조치·심각도·시간대를 승인권자와 한 행에 넣고, 연락표의 `〃`는 앞 행을 따르며, 다음 쪽 첫 행은 앞쪽의 심각도를 이어받는다. 3쪽의 선 없는 오탐률 표는 열 위치로 읽는다. ※1~3 설명은 해당 행에도 붙인다.
- `python -m soc.kb.ingest --dry-run --show 0`으로 **01번 요소 34개→청크 14개**, **09번 요소 103개→청크 92개**, **전체 120개 청크**를 확인했다. 01번 `호스트 네트워크 격리 → SOC 팀장`, `critical → 15분 이내`와 09번 평가 질문 k15~k21의 조건·답 7건을 각각 같은 표 청크 안에서 확인했다.
- 추가 패키지: 표 칸 좌표를 읽는 `pdfplumber>=0.11,<0.12`를 `requirements-kb.txt`에 추가했다. 실행 환경에서 `python -m pip install -r requirements-kb.txt`로 설치한다. 패키지가 없으면 `parse.py`가 설치 명령을 담은 오류를 낸다.
- 이 복원은 현재 제공된 01·09번 PDF의 배치에 맞춘다. PDF 판형·열 위치가 바뀌면 표 행과 승인권자를 다시 대조해야 한다. 05번 2단 읽기 순서, 06번 스캔 OCR, 07번 차트 수치는 이번 수정 대상이 아니다. Recall@3과 최종 답 정확도는 적재 후 따로 측정한다.
